# CraCha-Werbevideo „Frag deine Website“ (36,5 s, Fassung 3)

Komposition `CraChaAd` in `video/src/ad/`, alle Zeitmarken in `video/src/ad/cues.json`. Fassung 2: Voice-over statt Bildschirmtext, Chat ohne Fenster, mehr Zeit zum Sehen. Fassung 3: Pastell-Hintergrund der Landingpage, nur Urbanist, Browser mit vielen Tabs, bildliche Wissensbasis, schwarzer Punkt morpht zum Logo.

## Eckdaten

| | |
|---|---|
| Länge | 36,5 s, 120 BPM, 1 Beat = 0,5 s |
| Musik | Lyria-3-Take, Breakdown um 2 Takte verlängert (Teil 16–20 s wiederholt), ab dem Drop in das eigene Ende des Takes geschnitten |
| Stimme | Gemini 3.8 Flash TTS „Puck“, ein Take (`public/ad-vo-take.wav`), in 20 Phrasen auf den Beat gelegt |

## Ablauf

| Zeit | Stimme | Bild |
|---|---|---|
| 0–2 | „Wo stand das nochmal?“ | Wort-Stapel: „Wo“ groß, jedes weitere Wort ploppt darunter, der Block schiebt sich hoch und passt sich an |
| 2–7,5 | „Du klickst dich durch Dutzende Unterseiten. Immer wieder. Für eine einzige Info.“ | Stapel whippt nach oben, Website im Vollbild; jeder Klick (Tab-Leiste, Menü) öffnet einen Tab mehr; Zoom raus auf viele Browser voller Tabs; Kollaps zum schwarzen Punkt |
| 8–10 | „Mit Kratscha geht das einfacher.“ | Punkt morpht in die Buchstaben der Wortmarke und zurück |
| 10–12 | „Gib einfach deine Website ein.“ | Punkt → Eingabefeld, `example.com` tippt, Klick „Crawl starten“ |
| 12–16,5 | „Kratscha liest jede Unterseite und macht daraus deine Wissensbasis.“ | Kacheln wachsen Ring für Ring auf dem Beat, Kamera zoomt so weit raus, dass alles im Bild bleibt; Haken je Seite; die Seiten fließen auf Kurven in eine Datenbank, die sich orange füllt, „Wissensbasis bereit ✓“ |
| 16,5–21,5 | „Jetzt stellst du einfach deine Frage. Und bekommst die Antwort. Mit Quelle.“ | Nur Blasen: Frage tippt, steigt auf; Suche 1,5 s mit aufleuchtenden Seiten; Antwort mit Markierung; Quellen-Chip |

| 32–36,5 | „Kratscha. Frag deine Website. Jetzt kostenlos starten.“ | Schlusshit: Punkt morpht zur Wortmarke, Ringe, Claim, Button „Kostenlos starten“, `CRACHA-APP.COM` |
