# CraCha-Werbevideo „Frag deine Website“ (36 s, gebaut)

Komposition `CraChaAd` in `video/src/ad/`, Zeitmarken in `video/src/ad/cues.json`. Referenz dafür, wie der Skill umgesetzt ist.

## Eckdaten

| | |
|---|---|
| Länge | 36,0 s, 120 BPM, 1 Beat = 0,5 s = 30 Frames |
| Format | 1920×1080, 60 fps |
| Musik | Lyria 3 (Take 3), Beat 1 auf Frame 0, ab 28 s in das eigene Ende des Takes geschnitten (gleiche Phrasenposition) |
| Aussagen | nur Funktionen, keine Zahlen: Website eingeben, jede Unterseite wird gecrawlt, Wissensbasis, Chat, Antwort mit Quelle, Stelle auf der Seite markiert, kostenlos starten |
