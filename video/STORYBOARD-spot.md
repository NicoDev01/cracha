# CraCha-Spot „Der Crawl-Chat-Agent“ (18,5 s)

Komposition `CraChaSpot` in `src/spot/`, alle Zeitmarken in `src/spot/cues.json`. Stil nach dem Skill `cracha-werbevideo` (Referenz 3: Pacing, Referenz 1: Morphs). Nichts ragt aus dem Bild: Browser bei 90 %, Crawl-Kamera zoomt pro Ring logarithmisch auf eine Größe, bei der der ganze Ring passt, Quellseite 1400 × 800.

| Zeit | Stimme („Kratscha“ geschrieben) | Bild | Musik |
|---|---|---|---|
| 0–1,2 | „Wo stand das nochmal?“ | Wort-Stapel, Whip nach oben | Intro |
| 1,2–4,0 | „Du klickst und klickst und klickst.“ | Browser; auf jedem „klickst“ (1,48 / 2,32 / 3,24 s, aus der Lautstärke gemessen) ein Klick, ein Tab mehr; Zoom raus auf viele Browser, Kollaps zum Punkt | Riser, Stopp 3,5–4 |
| 4,0–5,2 | „Mit Kratscha nicht mehr.“ | Punkt morpht zur Wortmarke und zurück | Breakdown |
| 5,2–6,5 | „Gib einfach deine Website ein.“ | Punkt → Eingabefeld, `example.com`, Klick | |
| 6,5–9,1 | „Kratscha liest jede Unterseite und merkt sich alles.“ | Eingabefeld → Startseite, Seiten wachsen Ring für Ring, fließen in die Datenbank, Haken | Build, Pause vor dem Drop |
| 9,1–10,0 | „Dann frag einfach.“ | Datenbank → Frage-Feld, Frage tippt | |
| 10,0–12,2 | „Die Antwort kommt mit Quelle.“ | Senden = Drop, Frage wird Blase, Antwort mit Markierung, Quellen-Chip | Drop |
| 12,2–15,0 | „Ein Klick, und du siehst, wo es steht.“ | Chip wächst zur Originalseite, Marker, Kollaps zum Punkt | |
| 15,0–18,5 | „Kratscha, der Crawl-Chat-Agent. Jetzt kostenlos starten.“ | Punkt → Wortmarke, „der **Cra**wl-**Cha**t-Agent“, Button, `cracha-app.com` | Schlussakkord |
